APK QILISH (kompyuterda, 5 daqiqa)

1. github.com saytida bepul akkaunt oching (bor bo'lsa kiring).
2. Yangi repository yarating (New repository), nomi: shahar-oyini.
3. "uploading an existing file" ni bosing va shu zip ichidagi hamma narsani
   (www, .github, package.json, capacitor.config.json) tortib tashlang.
   DIQQAT: .github papkasi ham yuklansin.
4. Commit changes ni bosing.
5. Tepada Actions bo'limiga o'ting. "APK yasash" ishga tushadi (3-6 daqiqa).
6. Yashil belgi chiqqach, ishni oching, pastda Artifacts > shahar-oyini-apk ni yuklab oling.
7. Zip ichidagi app-debug.apk ni telefonga o'tkazing va o'rnating
   (Sozlamalarda "noma'lum manbalardan o'rnatish"ga ruxsat bering).
